# 吊牌扫码录入小程序
> 微信小程序，服装吊牌批量采集入库，扫码自动解析款号/颜色码/尺码，本地离线存储，支持导出CSV汇总表格，适合仓库盘点吊牌录入。

## ✨ 功能
1. 微信原生扫码API，稳定调用摄像头，扫码识别吊牌条形码
2. 条码自动解析规则：款号 + 3位颜色码 + 尺码
3. 款号字典记忆：同款商品自动回填品名、价格，大批量录入提速
4. 本地Storage离线存储，无需后端服务器，支持1000+条记录
5. 手动录入条码兜底，条码磨损时手工输入
6. 记录删除、导出CSV表格，WPS直接打开做汇总

## 🛠 技术栈
微信小程序原生 WXML + WXSS + JavaScript，本地存储，无后端。

## 🚀 运行方式
1. 微信开发者工具导入项目
2. 真机调试，手机扫码预览
3. 授权相机权限，即可扫码录入吊牌信息

## 📝 使用流程
1. 点击【开始扫码】扫描吊牌条码
2. 首次扫描该款号，填写品名、颜色名称、价格
3. 再次扫描同款，自动带出品名价格
4. 录入完成后，导出CSV汇总表，WPS打开编辑
